# GEMINI.md — Gedankenwelten

This project uses a shared AI instructions file: **AGENTS.md**

Please read `AGENTS.md` in this repository root before starting any task.
It contains the complete project structure, note pipeline, quality standards, and tag taxonomy.

Key points:
- Notes go into `content/Zeitgeist/`, `content/Denker/`, `content/Geistesblitz/`, `content/DenkerVita/` etc.
- New notes follow the 8-step pipeline documented in AGENTS.md
- Quality standard: ≥1,200 words, ≥5 quotes, fact-check for Zeitgeist notes
- Local wiki: `docker compose up` → http://localhost:8080
